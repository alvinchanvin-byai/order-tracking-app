Role: Admin

កំណត់ Master URL សម្រាប់ភ្ជាប់ Google Sheet "Tracking order"

ប្រព័ន្ធកណ្តាល (Master URL) កំណត់ដោយ Role Admin:

ពេល Admin រក្សាទុក URL នៅទីនេះ រាល់បុគ្គលិក ឬ User ទាំងអស់ដែលបើកដំណើរការ Web App នេះ (ទាំងលើទូរសព្ទ Phone និងកុំព្យូទ័រ PC) នឹងអាច Sync ទិន្នន័យបានភ្លាមៗដោយស្វ័យប្រវត្តិ ដោយមិនចាំបាច់ Setup ឬបញ្ចូលអ្វីឡើយ។

ឈ្មោះ Sheet តាមការកំណត់របស់អ្នក:

  • Google Spreadsheet Name: Tracking order
  • Sheet/Tab Name: Tracking

URL ដែលបានមកពីការ Deploy Apps Script លើ Google Sheet "Tracking order"

របៀបយក Web App URL (រៀបចំត្រឹមតែ 2 នាទី):
  1. បង្កើត Google Sheet ដាក់ឈ្មោះថា "Tracking order"
  2. ចុច Menu Extensions > Apps Script
  3. បើក File GoogleAppsScript_Code.gs (ក្នុង Folder Project នេះ) រួច Copy កូដទាំងអស់ទៅ Paste ចូល
  4. ជ្រើស Function setupAllSheets រួចចុច Run (ដើម្បីបង្កើត Sheet ទាំង 6: Tracking, Customer Information, BU, Package Type, Document Type, User Management ស្វ័យប្រវត្តិ)
  5. ចុចប៊ូតុង Deploy (ពណ៌ខៀវ) > New deployment
  6. ត្រង់កង់ធ្មេញ ជ្រើសយក Web app
  7. កំណត់ Execute as: Me និង Who has access: Anyone
  8. ចុច Deploy រួច Copy យក Web app URL មក Paste ខាងលើនេះជាការស្រេច!
